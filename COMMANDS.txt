SOCIETYOPS AI - COMMANDS
========================
All commands are for Windows PowerShell, run from the project folder:
    cd "C:\Users\JANHAVI TUPE\Downloads\societyops-ai"

If a command crashes with "JavaScript heap out of memory", close Spotify / extra
browser tabs / Prisma Studio, then put this in front of it on the same line:
    $env:NODE_OPTIONS="--max-old-space-size=2048";


1. FIRST-TIME SETUP (or after pulling new code)
-----------------------------------------------
npm install                      # install packages
npx prisma migrate deploy        # apply any new database changes
npx prisma generate              # rebuild the database client


2. RUN THE APP (development)
----------------------------
npm run dev
    -> open http://localhost:3000
    -> stop with Ctrl + C

IMPORTANT: after any backend change (src/routes, src/services, src/database,
src/auth, server.ts) press Ctrl + C and run "npm run dev" again.
Screen changes (src/app, src/components) reload by themselves.

One-time sign-in codes (OTP) are not texted yet: they are printed in this
terminal as   OTP for +91... (sign-in): 123456

Run on another port (e.g. if 3000 is busy):
    $env:PORT="3300"; $env:BETTER_AUTH_URL="http://localhost:3300"; $env:ALLOWED_ORIGINS="http://localhost:3300"; npm run dev


3. RUN THE APP (production build)
---------------------------------
npm run build                    # build the screens and server into dist/
npm start                        # run the built copy (does NOT see code changes until you build again)


4. DATABASE BROWSER (Prisma Studio)
-----------------------------------
npx prisma studio
    -> open http://localhost:5555
    -> stop with Ctrl + C
Edits made here change the real database straight away.


5. TESTS AND CHECKS
-------------------
npm test                         # all automated tests (uses its own "societyops_test" schema, never your data)
npx vitest run tests/worker.test.ts     # one test file
npm run typecheck                # TypeScript errors
npm run lint                     # code problems
npm run format                   # tidy code formatting


6. DEMO DATA
------------
Add the demo common areas and lifts to an existing database (adds only):
    npx tsx prisma/seedPlaces.ts

Wipe EVERYTHING and reload the demo societies, users, vendors and tickets:
    $env:SEED_RESET="true"; npx prisma db seed; Remove-Item Env:SEED_RESET
    (This deletes all your own data too: users, flats, vendors, tickets.)


7. CLEAR ALL TICKETS AND CHATS (keep users, flats, vendors)
-----------------------------------------------------------
& "C:\Program Files\PostgreSQL\18\bin\psql.exe" "postgresql://USER:PASSWORD@localhost:5432/DBNAME" -c 'BEGIN; DELETE FROM "AgentActivityLog"; DELETE FROM "NotificationLog"; DELETE FROM "TimelineEvent"; DELETE FROM "Ticket"; DELETE FROM "ChatMessage"; UPDATE "Vendor" SET "activeJobsCount" = 0; COMMIT;'
    Use the same USER, PASSWORD and DBNAME as DATABASE_URL in your .env file
    (leave off anything after "?" in that URL).


8. SAVE YOUR WORK (git)
-----------------------
git status                       # what changed
git add -A
git commit -m "describe what you did"
git push                         # send it to GitHub


9. BACKUP THE DATABASE
----------------------
npm run backup

10. JENKINS (http://localhost:8080)
-----------------------------------
The pipeline is in the Jenkinsfile. Without Docker it uses this machine's Node and
PostgreSQL, in its own schemas (jenkins_ci, jenkins_test): your data is never touched.

One-time setup:
  1. Push your code, so GitHub has the Jenkinsfile:   git push
  2. Jenkins > Manage Jenkins > Credentials > System > Global credentials > Add Credentials
       Kind: Secret text
       Secret: the DATABASE_URL value from your .env file
       ID: societyops-database-url
  3. Jenkins > New Item > name "societyops-ai" > Pipeline > OK, then under Pipeline:
       Definition: Pipeline script from SCM
       SCM: Git
       Repository URL: https://github.com/janhavitupe/SOCIETYOPS-AI.git
       Branch Specifier: */phase-1        (or */main once merged)
       Script Path: Jenkinsfile
     Save.

Every build:
  Jenkins > societyops-ai > Build Now
  Click the build number > Console Output to watch it, Test Results to see each test.
  It needs about 2 GB of free memory: close Prisma Studio and npm run dev first.

Automatic builds on every push:
  The Jenkinsfile tells Jenkins to check GitHub every 2 minutes and build any new
  commit. It switches on after the first build you start by hand (Build Now once).
  Builds run on what is pushed to GitHub, so: commit, then git push.
  To build every branch, not only phase-1, make the job a "Multibranch Pipeline"
  with the same repository URL instead of a plain Pipeline.
